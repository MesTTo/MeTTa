# Space as a projection of door rows

Goal: declare each Python door once, generate its public projections, publish the contracts at engine boot, and let packages contribute namespaced doors through the seam.
Constraint: the engine implements MeTTa semantics. This change owns the Python seat and preserves the existing implementation bodies, resource ownership, answer multiplicity, and refusal boundaries.
