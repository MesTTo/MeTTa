# One refinement vocabulary
Goal: `Annotated[int, Gt(0)]` in a signature, `(Annotated Number (Gt 0))` in a declaration, a refused call naming the constraint and the value, and a property test written from the same declaration, with one vocabulary behind all four.
Constraint: the reader keeps its existing rule (an Atom refines, other metadata stays in the annotation claim); `(Shape ...)` keeps declared-type unification as its only acceptance; the arbiter is upstream PeTTa at the parity pin, which has no refinements, so every shape here is this engine's own and is recorded as such.
