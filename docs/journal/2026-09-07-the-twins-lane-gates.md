# The twins lane gates
Goal: every Python twin's claims and budget decide the gate, so a library change that breaks a claim a twin makes is red on the next battery instead of printed by a REPORT lane nobody reads.
Constraint: a lane is promoted only when it is green on the tree it gates; a twin whose claim stopped holding is repaired to the example's claim, never widened, and a budget moves only with its mechanism written beside it.
