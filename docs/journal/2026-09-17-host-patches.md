Goal: every `docs/host-workarounds.md` entry whose defect lives in SWI-Prolog or janus is fixed in the host this tree runs on, recorded as a `Patch:` entry, and its sites lifted.
Constraint: the patched host is a local build of swipl-devel at the tag the seat runs (V10.1.14); SWI's own suite must pass on it; the ledger lane answers `absent` for a patched entry and `present` for a worked-around one, so an environment without the patch is refused by name; every site is lifted in its own commit.
