# Refusals

Every refusal the engine raises on purpose has a ROW in the `&metta` catalog,
and this page is those rows. A row says four things: the kind word the engine
classifies a raised ball into, the class name a seat raises for it, the
authority the refusal stands on, and the repair.

GENERATED by `extensions/python/tools/refusalsdoc.py` from the running
engine's own rows; edit the declarations in `engine/spaces/catalog.pl` and
rerun it with `--write`, never this page.

Ask the same question yourself, since a row is ordinary data:

```metta
!(match &metta (refusal $kind $class $ground $remedy) ($kind $class))
```

A HOST reads the row at the crossing rather than building a table of its own.
In Python every engine refusal carries `.ground` and `.remedy`; in TypeScript
the same two ride on `MettaError`; in C they are `mt_ground()` and
`mt_remedy()` beside `mt_errmsg()`. The remedy's `<field>` holes are filled
from the refusal that was actually raised, so a tripped bound reads `raise the
bound past 0.05 seconds`. A hole left over is one the engine has no opinion
about, which is what keeps that remedy `prose`. A hole is written here as
code, `` `<limit>` ``, and is a plain word in the rendered sentence.

Each seat spells a class its own way where its own language already owns the
word; `tests/data/error-kinds.json` records what it spells and why.

## Each kind

### `syntax`

Raised as `MettaSyntaxError`, off the reserved control envelope.

**Ground.** metta-law: HostLaws: engine/filereader.pl metta_host_rethrow_syntax/1 -- text the reader cannot read stops the load, at the line it stopped on

**Remedy.** close or correct the form that starts at line `<line>`

An LSP `quickfix` at rustc's `prose`, with no act: the repair is a decision.

### `time_limit`

Raised as `TimeLimitError`, off the reserved control envelope.

**Ground.** metta-law: HostLaws: engine/metta/control.pl metta_pragma_key/2 max-time -- a wall-clock bound stops the evaluation where it stands, and the writes it already made stand with it

**Remedy.** raise the bound past `<limit>` seconds, or narrow the query

An LSP `quickfix` at rustc's `prose`, whose act is `(edit (pragma! max-time <seconds>))`.

### `inference_limit`

Raised as `InferenceLimitError`, off the reserved control envelope.

**Ground.** metta-law: HostLaws: engine/metta/control.pl metta_pragma_key/2 max-inferences -- an inference bound stops the evaluation where it stands, and the writes it already made stand with it

**Remedy.** raise the bound past `<limit>` inferences, or narrow the query

An LSP `quickfix` at rustc's `prose`, whose act is `(edit (pragma! max-inferences <inferences>))`.

### `restraint`

Raised as `RestraintError`, off the reserved control envelope.

**Ground.** metta-law: HostLaws: engine/spaces/catalog.pl (cache F (max-answers N)) -- a bound a program declared for one of its own tables stops the call that passed it, naming the bound rather than answering fewer rows in silence

**Remedy.** raise the `<restraint>` bound past `<bound>` in the row that declares it, or ask `<call>` for fewer answers

An LSP `quickfix` at rustc's `prose`, with no act: the repair is a decision.

### `interrupted`

Raised as `Interrupted`, off the reserved control envelope.

**Ground.** metta-law: HostLaws: engine/metta/registration.pl metta_host_error_kind_row/3 interrupted -- a run stopped from outside reports the stop, so a caller tells it from a fault

**Remedy.** start the run again if the stop was not meant

An LSP `source` at rustc's `prose`, with no act: the repair is a decision.

On TypeScript this is `InterruptedError`: every condition in this package ends in Error, which is the platform's own convention for an Error subclass, and JavaScript has no builtin of that name to collide with.

### `value`

Raised as `WireError`, off the reserved control envelope.

**Ground.** metta-law: HostLaws: engine/json_codec.pl -- the crossing carries only values JSON can carry and refuses the rest by name, rather than coercing them

**Remedy.** give the crossing a value JSON can carry, or carry the whole thing as a grounded atom

An LSP `quickfix` at rustc's `prose`, with no act: the repair is a decision.

On Python this is `ValueError`: Python's own word for a value it cannot use; the refusal is about the caller's data rather than about MeTTa, so the language's class is the one a caller writes in except.

### `type`

Raised as `CastError`, off the reserved control envelope.

**Ground.** metta-law: HostLaws: engine/json_codec.pl -- a term that is not JSON data at all is refused as a type rather than as a value, so a caller tells a bad number from a bad shape

**Remedy.** carry this term whole as a grounded atom instead of as data

An LSP `quickfix` at rustc's `prose`, with no act: the repair is a decision.

On Python this is `TypeError`: Python's own word for a term of the wrong type; metta.convert.CastError already names a different meaning on this seat, a cast() refusal, so the row's name is taken here.

### `assertion`

Raised as `AssertionFailure`, off a ball whose own shape names the refusal.

**Ground.** metta-law: HostLaws: engine/metta/runtime.pl report_failed_assertion/4 -- a false claim is printed and thrown under the MeTTa head the program wrote, so a harness separates it from a broken engine

**Remedy.** correct the claim `<operation>` makes, or the equations it reads

An LSP `quickfix` at rustc's `prose`, with no act: the repair is a decision.

On TypeScript this is `AssertionError`: node:assert's own word for the same meaning, and this host has no builtin assert statement whose class it would shadow.

### `capability`

Raised as `SpaceCapabilityError`, off a ball whose own shape names the refusal.

**Ground.** metta-law: HostLaws: engine/spaces/lifecycle.pl metta_host_space_capability_error/4 -- a space door requires its declared engine or provider capability

**Remedy.** grant `<capability>` to `<space>`, which `<operation>` needs

An LSP `quickfix` at rustc's `maybe`, whose act is `(edit (grants <space> <capability>))`.

On TypeScript this is `CapabilityError`: the package namespace already says space, so the Space prefix would be said twice.

### `platform`

Raised as `PlatformCapabilityError`, off a ball whose own shape names the refusal.

**Ground.** metta-law: HostLaws: engine/metta.pl metta_require_platform/2 -- a form that cannot work without a platform capability refuses before it tries, naming what this build would have to be made with

**Remedy.** build this deployment with `<requires>`, which is what the `<capability>` capability needs; without it `<costs>`

An LSP `quickfix` at rustc's `prose`, with no act: the repair is a decision.

### `operation`

Raised as `MettaOperationError`, off a ball whose own shape names the refusal.

**Ground.** arbiter: upstream PeTTa at the parity pin: tests/conformance/petta/expected/he_error.metta.out answers Error to (catch (+ 40 a)), so a builtin refusing a value is a VALUE inside MeTTa and becomes a host exception only at the crossing

**Remedy.** give `<operation>` a `<expected>` where it got `<culprit>`

An LSP `quickfix` at rustc's `prose`, with no act: the repair is a decision.

On TypeScript this is `OperationError`: the package namespace already says metta, so the Metta prefix would be said twice.

### `stack`

Raised as `StackLimitError`, off a ball whose own shape names the refusal.

**Ground.** metta-law: HostLaws: engine/metta/control.pl metta_pragma_key/2 stack-limit -- the ceiling in force when the stack ran out is the one the refusal names, not the one in force now

**Remedy.** raise the ceiling past `<limit>` bytes, or make the recursion shallower

An LSP `quickfix` at rustc's `prose`, whose act is `(edit (pragma! stack-limit <bytes>))`.

### `source`

Raised as `SourceNotFound`, off a ball whose own shape names the refusal.

**Ground.** metta-law: HostLaws: engine/filereader.pl -- a source a program names is read only once it exists, and the refusal carries the path rather than the sentence about it

**Remedy.** create `<source>`, or correct the path that names it

An LSP `quickfix` at rustc's `prose`, with no act: the repair is a decision.

On TypeScript this is `SourceNotFoundError`: every condition in this package ends in Error; the row keeps the shorter name because the Python seat's own N818 exemption records that spelling as deliberate.

### `engine`

Raised as `EngineError`, off a ball this engine did not shape.

**Ground.** metta-law: HostLaws: engine/metta/registration.pl metta_host_error_kind/3 -- a ball this engine did not shape is reported as itself rather than classified by guess

**Remedy.** report the ball with the message it carries; this engine did not shape it

An LSP `source` at rustc's `prose`, with no act: the repair is a decision.
